# Заметки (Notes App) — Project Brief

## Описание проекта

Приложение для создания и хранения личных заметок. Пользователь должен иметь возможность быстро записывать мысли, идеи и важную информацию, чтобы ничего не забывать, а также удобно организовывать и находить нужные заметки среди большого количества.

## Цель

Дать пользователю простой и удобный инструмент для ведения личных заметок с базовой организацией (по категориям), приватностью (каждый видит только своё) и быстрым поиском.

## User Stories

- Создание заметок, чтобы фиксировать важные мысли.
- Редактирование заметок, для обновления устаревшей информации.
- Удаление заметок, для удаления не нужных уже не актуальных.
- Распределение заметок по категориям, чтобы легче было искать и связывать заметки (личное, финансы, работа и т.п).
- Приватность заметок, важно чтобы мои заметки никто не видел кроме меня и так же наоборот.
- Поиск по названию, среди большого количества заметок легко запутаться и не найти нужный, важно чтобы я мог по названию найти свою заметку.
- Так же пагинация заметок, не нужно грузить всё в 1 страницу.

## Функциональные требования

1. Создание заметки (заголовок, текст, дата создания).
2. Редактирование заметки.
3. Удаление заметки.
4. Категории/папки для заметок, привязка заметки к категории.
5. Доступ к созданию/редактированию/удалению только для авторизованных пользователей.
6. Разграничение доступа: пользователь видит и может редактировать/удалять только свои заметки.
7. Поиск заметок по заголовку.
8. Пагинация списка заметок.
